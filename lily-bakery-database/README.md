# Lily's Bakery Database
A database project created for my college SQL course based on a bakery business.
## Technologies
* SQL
* Relational Database
## Project
This project focuses on designing and working with a relational database for Lily's Bakery. It includes database tables, relationships, and SQL queries used to manage and retrieve bakery-related data.
## Skills Demonstrated
* Database design
* SQL queries
* Tables and relationships
* Data management
* Relational databases
